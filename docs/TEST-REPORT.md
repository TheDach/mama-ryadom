# Отчёт о проверке

Дата: 30.09.2026. Версия: 1.1.0, исправления обработки кнопок. Среда: Linux, Node.js 24.19.0.

## Выполнено

- `npm test`: 50 тестов, 0 ошибок.
- `npm run check`: синтаксис JavaScript, структура OpenAPI JSON и исключение рабочего окружения из Git проверены.
- `npm run api:check -- --local`: полный сценарий API на локальном HTTP-сервере пройден.
- Контрольные суммы файлов сверены перед упаковкой.
- После добавления логотипа проверены /logo.png, совместимый адрес favicon, MIME-тип image/png, совпадение байтов с исходным PNG, ссылки HTML и синтаксис генератора презентации.

Проверены все ветки анкеты, общий профиль бота и мини-приложения, повторные и устаревшие callbacks, подпись MAX, изоляция сессий, конфликт версии и хранение SQLite. Дополнительно проверены callbacks с исходным сообщением бота, реальный HTTP-маршрут webhook, отправка на /answers, резервное сообщение при отказе MAX, подписка на message_callback, лимит напоминаний, недопустимые статусы, очистка кэша при удалении, повтор подтверждения удаления, миграция прежней базы и удаление во время доставки напоминания.

Запросы к MAX в автоматических тестах заменены контролируемым транспортом. Эти тесты подтверждают обработку формата события и запросов, но не являются проверкой опубликованного бота.

## Внешние проверки

- Docker Engine в среде проверки отсутствует. Workflow Verify содержит сборку с лимитом 300 секунд без загрузки базового образа, запуск контейнера, проверку API и повторный запуск; выполнение workflow ещё не подтверждено.
- Chromium в среде отсутствует. Визуальная проверка мобильного и веб-клиента MAX не выполнялась. Интерфейс мини-приложения сохранён; его API и общая логика анкеты прошли проверки.
- Рабочий токен MAX не предоставлен. Доставка настоящих событий, работа в двух клиентах и постоянная доступность хостинга проверяются владельцем после развёртывания. deploymentVerified остаётся false.
- Презентация из исходного архива сохранена как текущий черновик; в этот прогон её содержание и оформление не оценивались.
- Каталог остаётся демонстрационным. Юридическая актуальность выплат и проведённый пилот не заявляются.
