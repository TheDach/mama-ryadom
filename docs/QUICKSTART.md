# С чего начать

1. Распакуйте ZIP, перейдите в каталог `mama-ryadom`.
2. Для просмотра без MAX выполните `docker compose up --build -d` и откройте http://localhost:3000. Без Docker: установите Node.js 24, выполните `npm ci`, затем `npm start`.
3. Для бота заполните строку `BOT_TOKEN=` в существующем `.env`, затем перезапустите приложение. Не вставляйте звёздочки: нужен настоящий токен. В режиме polling бот должен быть без webhook-подписки.
4. Для мини-приложения MAX дополнительно заполните `BOT_USERNAME`, разверните приложение на публичном HTTPS-адресе и укажите его в `PUBLIC_URL` и настройках mini app у бота.
5. Публичный запуск: `DEMO_MODE=false`, `BOT_MODE=webhook`, случайный `WEBHOOK_SECRET`, затем `docker compose exec app node scripts/max-setup.js`.
6. Прочитайте `README.md`, пройдите `docs/JUDGE-CHECKLIST.md` в мобильном и веб-клиенте MAX.
7. Перед сдачей заполните `docs/submission.json`, обновите `docs/presentation.pdf`, адреса API и контрольную сумму финального архива.

Файл `.env` не исключён в `.gitignore`, как запрошено. Пустой файл входит в поставку. Заполненный секретами файл не публикуйте: кейс запрещает рабочие токены в репозитории.

В `docs/TEST-REPORT.md` точно указано, что проверено и что требует проверки в вашей среде. Проект не является официальным сервисом назначения выплат.
