# Сценарий проверки

Все ответы ниже вымышлены. Каталог и расчёт демонстрационные.

## Основной путь

1. Открыть бота MAX, отправить `/start`.
2. Выбрать «Подобрать поддержку» и подтвердить использование тестовых данных.
3. Пройти ветку: «Беременность», «30 недель и больше», «Один ребёнок, первый родной», «По трудовому договору», «РФ, постоянная регистрация», «Ниже прожиточного минимума».
4. На последнем шаге оставить выплаты без отметок и выбрать «Готово».
5. Проверить результат: №1 потенциально подходит, №4 требует уточнения. «Ближайший шаг» показывает документы и организацию.
6. «Посмотреть подборку» открывает мини-приложение с теми же ответами.
7. Открыть карточку, добавить в личный список, поменять статус. Это отметка пользователя, не статус ведомства.
8. В настройках включить незавершённые действия, выбрать тёмную тему и нажать «Подтвердить». После повторного открытия оба значения должны сохраниться.
9. В карточке запланировать напоминание на ближайшее время. Проверить доставку в MAX.

## Ветвление и восстановление

- Беременность: после первого ответа появляется вопрос о сроке, всего 7 шагов.
- Ребёнку меньше 1,5 лет: второй вопрос о возрасте в месяцах, всего 7 шагов.
- Ребёнку от 1,5 до 3 или от 3 до 7 лет: вопроса о беременности и младенческом возрасте нет, всего 6 шагов.
- Работающий родитель нескольких детей: вопрос о доходе содержит пояснение про 1,5 ПМ.
- Возврат на первый шаг и смена беременности на ребёнка: старый срок беременности удалён.
- Неизвестный доход: доступен вариант «Не знаю», результат содержит уточнения.
- Уже оформленные меры сохраняются при смене жизненного этапа.
- Начать опрос в боте, подтвердить два ответа, открыть профиль в приложении. Продолжить с того же шага.
- Открыть приложение заново после подтверждения ответа. Черновик сохранён.
- Нажать устаревшую кнопку в боте. Ответы не меняются, доступно продолжение текущего опроса.

## Интерфейс

- На экране настроек одна общая кнопка «Подтвердить», отдельно от разделов формы.
- Смена темы даёт предпросмотр. «Отменить» возвращает сохранённую тему и флаги уведомлений.
- Переключение системной темы, крупный шрифт и повышенный контраст читаемы.
- Каталог, фильтры, сравнение и карточка работают на узком экране.
- При потере сети есть сообщение об ошибке. Повтор сохранения не требует проходить анкету заново.
- При конфликте версии загружается актуальное состояние. Изменения другого окна не перезаписываются молча.
- Кнопка открытия приложения в меню бота доступна до опроса.
- `/stop` отключает уведомления. `/delete` удаляет профиль, связанные ответы MAX и отзывает сессии.
- После `/start` каждая кнопка приветствия отвечает; первый вопрос появляется после согласия.
- При 30 напоминаниях новая попытка показывает сообщение о лимите, следующая кнопка работает.

## Воспроизводимость

```bash
npm ci
npm test
npm run check
npm run api:check -- --local
docker compose up --build -d
docker compose ps
docker compose logs --tail=100 app
```

Сборка Docker должна занять не более 5 минут без первоначальной загрузки базового образа. Время фиксируется на машине проверки. После перезапуска контейнера профиль и напоминания сохраняются в volume.
