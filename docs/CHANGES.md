# Исправления от 30.09.2026

- Добавлен логотип в интерфейс, иконку страницы, README и генератор презентации.

- Callback обрабатывается, даже если вложенное исходное сообщение отправлено ботом.
- При запуске в webhook-режиме включаются события кнопок; ошибки регистрации повторяются с задержкой.
- Неуспешный callback-ответ с HTTP 200 учитывается; результат отправляется новым сообщением.
- Лимит напоминаний сообщает пользователю о причине отказа и не прерывает обработку событий.
- Валидация API отклоняет унаследованные имена свойств, неизвестные поля и некорректные типы.
- Удаление профиля очищает сессии и кэш ответов MAX. Миграция поддерживает существующую базу.
- Удаление во время доставки напоминания не создаёт профиль заново.
- Добавлены регрессионные тесты, сценарий API, проверка контрольных сумм и workflow для Docker.

# Изменения в 1.1.0

- Вместо фиксированных 8 вопросов используется банк из 15 вариантов. Пользователь проходит 6 или 7 шагов.
- Срок беременности и возраст младенца уточняются только в нужной ветке. Формулировка дохода учитывает занятость и состав семьи.
- Бот и мини-приложение сохраняют общий черновик после каждого подтверждения. Возврат назад и устаревшие кнопки обрабатываются по текущему состоянию.
- Карточки используют уточнённый возраст и срок для пояснения результата. Демонстрационный статус данных сохранён.
- Интерфейс получил нейтральное оформление без декоративного баннера и рекламных текстов.
- Настройки собраны в общую форму. Есть предпросмотр, одна кнопка «Подтвердить» и отмена изменений.
- Раздел «Мои заявки» переименован в «Мои выплаты». Планирование напоминаний перенесено к личному списку и карточкам.
- README, инструкции, презентация и описание API обновлены под текущий сценарий.
- Рабочий `.env` исключён из поставки, Git и Docker-образа.
- Compose запускает демо без файла окружения. Docker healthcheck учитывает `PORT`.
- В контейнер подключён bundle сертификатов. `PUBLIC_URL` проверяется как прямой адрес без перенаправлений и параметров.

Существующая SQLite-база совместима с обновлением. Завершённые профили сохраняются. Незавершённая старая анкета возвращается на первый шаг с ранее введёнными ответами. Миграция не удаляет трекер или напоминания.

Новая версия пока не развёрнута на вашем сервере. Контрольный список внешних проверок находится в `JUDGE-CHECKLIST.md`.
