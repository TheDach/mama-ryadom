## Внешние условия

Код и архив не подтверждают доступность MAX, сроки работы хостинга, время сборки на машине жюри и соответствие непредоставленным правилам мероприятия. Эти пункты проверяются перед сдачей. Сервис остаётся демонстрационным до экспертной проверки каталога и подготовки условий обработки реальных данных.

В поставке нет рабочих секретов. Исключение `.env` защищает будущие изменения, но не удаляет ранее сохранённые файлы из истории Git. Проверка доступа к прежней истории остаётся у владельца репозитория.

Служебная информация для жюри передаётся по правилам организаторов. Публичная версия презентации содержит реквизиты без токенов. Закрытая техническая версия может содержать необходимые секреты, если именно такой способ предусмотрен организаторами. Она не включается в Git.
