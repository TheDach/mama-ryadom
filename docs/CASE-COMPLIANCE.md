# Соответствие кейсу «Забота о людях»

| Требование | Реализация / материал | Что нужно после распаковки |
|---|---|---|
| Конкретная пользовательская проблема | Беременность / дети до 3 лет в Томской области, README, ARCHITECTURE | Проверка гипотез в пилоте |
| Основной сценарий в MAX | Адаптер Bot API, 8 вопросов, summary и следующий шаг | Токен, созданный бот, live-проверка |
| Mini app только в связке с ботом | MAX Bridge, HMAC initData, open_app, общий профиль | Привязать HTTPS URL на платформе MAX |
| MAX mobile и web | Адаптивный интерфейс и единый API | Пройти оба клиента с настоящим ботом |
| Не выдавать модель за решение ведомства | Маркировка каждого результата, ручные статусы, отсутствие подачи | Соблюдать ограничения при демонстрации |
| Тестовые данные | 18 записей, demo profiles, testData, источники, версии | Для реального пилота проверить сведения |
| Минимизация данных | Категории, ID MAX, согласие, удаление | Политика оператора и правовые основания реального пилота |
| Нет рабочих секретов в репозитории | В архиве токены пусты, .env.example | Не коммитить заполненный .env |
| Зафиксированный исходный код | ZIP и внешняя SHA-256, внутренний MANIFEST | Зафиксировать финальную версию сдачи |
| README | Сценарий, архитектура, окружение, данные, проверка, остановка | Внести реквизиты развёртывания |
| Зависимости и Docker | package-lock.json, Dockerfile, compose.yaml, .dockerignore | Проверить Docker в своей среде |
| PDF-презентация | docs/presentation.pdf и генератор | Заполнить служебный слайд |
| Собственный API | openapi.json, DATA-API.yaml | Публичный HTTPS URL и сессия MAX |
| Масштабирование и пилот | ARCHITECTURE и презентация | Это план, не вымышленные результаты |
| Доступность весь период проверки | Конфигурация restart и volume | Работающий сервер и мониторинг владельца |

Архив покрывает программную часть и материалы. Действующие ссылки, создание аккаунта, секреты и фактический допуск жюри не могут быть заранее включены без инфраструктуры владельца. Локальные тесты не подтверждают прохождение live-сценария MAX.
